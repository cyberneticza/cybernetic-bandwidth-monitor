NetTrace install guide · Option 1

Run portable, no installation

NetTrace {{VERSION}} · Package Option1-Portable · Prepared {{DATE}}

NetTrace shows which applications use your network, how good your connection is, and how fast it is. In this option you copy one program file to a folder and run it. Nothing is registered with Windows: no Start Menu entry and no entry under Settings › Apps. If you want those, use Option 2.

Before you start

RequirementDetail
WindowsWindows 10 version 2004 or later, or Windows 11, 64-bit (x64).
AccountA standard user account is enough. No administrator rights are needed.
.NETNot needed. The runtime is built into NetTrace.exe.
PowerShellThe commands in this guide work in the built-in Windows PowerShell. PowerShell 7 is not required for this option (see the appendix if you want it anyway).
Disk spaceAbout 120 MB for the program, plus the history it collects (usually a few MB a month).

What is in this package

FilePurpose
NetTrace.exeThe whole application.
appsettings.jsonOptional tuning (sampling, retention, quality checks). Keep it next to the exe.
NetTrace-Option1-Install-Guide.pdfThis guide. Not needed on the device.
Where the data goes The program can live in any folder, but the history it collects is always stored for the signed-in user in %LocalAppData%\NetTrace (database, preferences and logs).

Install

Run every command below in Windows PowerShell as your normal user (not "Run as administrator").

1

Copy the package to the device

Copy the Option1-Portable folder to the device, for example from a USB drive or a network share, into your Downloads folder. Then tell PowerShell where it is and where NetTrace should live. Change the first line if you copied it somewhere else:

$source = "$env:USERPROFILE\Downloads\Option1-Portable"
$target = "$env:USERPROFILE\Apps\NetTrace"
2

Copy NetTrace into its folder

New-Item -ItemType Directory -Force -Path $target | Out-Null
Copy-Item -Path "$source\*" -Destination $target -Exclude *.pdf -Force
3

Unblock the files

Files that arrived by browser, email or Teams are marked as "downloaded from the internet", which makes Windows SmartScreen stop the program. Remove the mark:

Get-ChildItem $target | Unblock-File
4

Start NetTrace

Start-Process "$target\NetTrace.exe"

The window opens and a NetTrace icon appears in the system tray (click ^ next to the clock if it is hidden). Closing the window keeps NetTrace running in the tray; right-click the tray icon › Exit NetTrace to stop it.

5

Optional: start NetTrace when you sign in

In NetTrace, open Settings and, under Running in the background, tick Start NetTrace when I sign in. This adds a scheduled task for your account only. Or run the following; NetTrace turns it into the same task the next time it starts:

Set-ItemProperty -Path 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Run' `
    -Name 'NetTrace' -Value "`"$target\NetTrace.exe`" --minimised"

This remembers the program's current folder, so do not move the folder afterwards.

6

Optional: record from Windows startup

To record even before anyone signs in, or while NetTrace is closed, select Install service in the same section. This needs administrator approval once, and moves the history to C:\ProgramData\NetTrace.

Check that it is running

Get-Process NetTrace | Select-Object Id, Path, StartTime

Upgrade to a newer version

Copy the new Option1-Portable folder to the device, set $source and $target as in step 1, then:

Stop-Process -Name NetTrace -Force -ErrorAction SilentlyContinue
Start-Sleep -Seconds 1
Copy-Item -Path "$source\*" -Destination $target -Exclude *.pdf -Force
Get-ChildItem $target | Unblock-File
Start-Process "$target\NetTrace.exe"

Your history is kept; the database upgrades itself on first start.

Uninstall

Installed the Windows service? Remove it first: in NetTrace, open Settings › Running in the background and select Remove service. That copies the history back to your own folder.
1

Stop NetTrace

Right-click the tray icon › Exit NetTrace, or run:

Stop-Process -Name NetTrace -Force -ErrorAction SilentlyContinue
2

Stop it starting at sign-in

Unregister-ScheduledTask -TaskName "NetTrace at sign-in ($env:USERNAME)" `
    -Confirm:$false -ErrorAction SilentlyContinue
Remove-ItemProperty -Path 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Run' `
    -Name 'NetTrace' -ErrorAction SilentlyContinue
3

Delete the program folder

Remove-Item "$env:USERPROFILE\Apps\NetTrace" -Recurse -Force

Use your own folder if you chose a different $target when installing.

4

Optional: delete the collected history

Skip this step to keep your history for a later reinstall.

Remove-Item "$env:LOCALAPPDATA\NetTrace" -Recurse -Force

Troubleshooting

What you seeWhat to do
"Windows protected your PC"Run step 3 (Unblock-File) again, or click More info › Run anyway. NetTrace is not code-signed, so SmartScreen does not recognise it.
Antivirus or company security tool blocks or quarantines NetTrace.exeNetTrace reads per-application network usage and the connection list, which security tools can flag. On a work device, ask IT to allow it.
Copy fails: "file is being used by another process"NetTrace is still running. Exit it from the tray, then copy again.
Anything elseLogs are in %LocalAppData%\NetTrace\logs. NetTrace's Settings and About pages both open the folder.

Appendix: installing PowerShell 7

This option does not need PowerShell 7. Install it only if you also want Option 2 on this device, or prefer it.
