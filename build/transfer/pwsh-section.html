Check whether PowerShell 7 is already installed

Open Windows PowerShell (Start › type PowerShell) and run:

Get-Command pwsh -ErrorAction SilentlyContinue
pwsh -NoProfile -Command '$PSVersionTable.PSVersion'

If the first command prints a path and the second prints 7.x, PowerShell 7 is installed and you can skip the rest of this section. If nothing is printed, or you see "The term 'pwsh' is not recognized", install it using one of the methods below.

MethodAdmin rightsWhen to use it
A. winget (package)Yes (UAC prompt)You are an administrator on the device.
B. winget (Microsoft Store)NoStandard user, and the Microsoft Store is allowed on the device.
C. Microsoft install scriptNoStandard user, and the Store is blocked or winget is missing.

Method A: winget, installed for all users

winget install --id Microsoft.PowerShell --source winget `
    --accept-package-agreements --accept-source-agreements

Method B: winget from the Microsoft Store, current user only

winget install --id 9MZ1SNWT0N5D --source msstore `
    --accept-package-agreements --accept-source-agreements

If winget itself is not recognised, install App Installer from the Microsoft Store, or use method C.

Method C: Microsoft's install script, current user only

Downloads PowerShell 7 from Microsoft into %LocalAppData%\Microsoft\powershell and adds it to your user PATH:

$installer = Invoke-RestMethod 'https://aka.ms/install-powershell.ps1'
Invoke-Expression "& { $installer } -AddToPath"
Security software may block this command. Downloading a script and running it straight away is a pattern that antivirus and company endpoint tools watch for. On a managed device, prefer method A or B, or ask IT to install PowerShell 7.

After installing

Close and reopen the PowerShell window so the new PATH is picked up, then confirm:

pwsh -v
