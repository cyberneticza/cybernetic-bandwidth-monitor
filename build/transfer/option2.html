Cybernetic Bandwidth Monitor install guide · Option 2

Install for the current user

Cybernetic Bandwidth Monitor {{VERSION}} · Package Option2-Install · Prepared {{DATE}}

Cybernetic Bandwidth Monitor shows which applications use your network, how good your connection is, and how fast it is. In this option an install script sets Cybernetic Bandwidth Monitor up properly for the signed-in user: it copies the program to %LocalAppData%\Programs\CyberneticBandwidth, adds a Start Menu shortcut, adds Cybernetic Bandwidth Monitor to Settings › Apps so it can be uninstalled from there, and can start it when you sign in. No administrator rights are needed and nothing is installed for other users.

Install

Run the commands in a PowerShell window as your normal user (not "Run as administrator").

1

Make sure PowerShell 7 is installed

pwsh -v

If this prints PowerShell 7.x, go to step 2. Otherwise follow Installing PowerShell 7 at the end of this guide, then come back.

2

Copy the package to the device

Copy the whole Option2-Install folder to the device (keep the app subfolder inside it), for example into your Downloads folder. Then tell PowerShell where it is. Change the path if you copied it somewhere else:

$source = "$env:USERPROFILE\Downloads\Option2-Install"
3

Unblock the files

Files that arrived by browser, email or Teams are marked as "downloaded from the internet". That mark makes PowerShell refuse the scripts and SmartScreen stop the program. Remove it:

Get-ChildItem $source -Recurse | Unblock-File
4

Run the installer

To install and start Cybernetic Bandwidth Monitor automatically when you sign in (recommended):

pwsh -NoProfile -ExecutionPolicy Bypass `
    -File "$source\install-peruser.ps1" -SourcePath "$source\app" -Autostart

To install without starting at sign-in, leave out -Autostart:

pwsh -NoProfile -ExecutionPolicy Bypass `
    -File "$source\install-peruser.ps1" -SourcePath "$source\app"

-ExecutionPolicy Bypass applies to this one command only; it does not change the device's policy. The installer finishes with "Installed. Launch it from the Start Menu…".

5

Start Cybernetic Bandwidth Monitor

Open Start › Cybernetic Bandwidth Monitor, or run:

Start-Process "$env:LOCALAPPDATA\Programs\CyberneticBandwidth\CyberneticBandwidth.exe"

A Cybernetic Bandwidth Monitor icon appears in the system tray (click ^ next to the clock if it is hidden). Closing the window keeps Cybernetic Bandwidth Monitor running in the tray; right-click the tray icon › Exit Cybernetic Bandwidth Monitor to stop it.

6

Optional: record from Windows startup

To record even before anyone signs in, or while Cybernetic Bandwidth Monitor is closed, open Settings › Running in the background in Cybernetic Bandwidth Monitor and select Install service. This needs administrator approval once, and moves the history to C:\ProgramData\CyberneticBandwidth. Start at sign-in can be switched on or off there too.

Check the installation

Get-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Uninstall\CyberneticBandwidth' |
    Select-Object DisplayName, DisplayVersion, InstallLocation
Get-Process CyberneticBandwidth | Select-Object Id, Path, StartTime

Upgrade to a newer version

Exit Cybernetic Bandwidth Monitor first (right-click the tray icon › Exit Cybernetic Bandwidth Monitor); a running copy locks the program file. Copy the new Option2-Install folder to the device, then repeat steps 2 to 4:

Stop-Process -Name CyberneticBandwidth -Force -ErrorAction SilentlyContinue
$source = "$env:USERPROFILE\Downloads\Option2-Install"
Get-ChildItem $source -Recurse | Unblock-File
pwsh -NoProfile -ExecutionPolicy Bypass `
    -File "$source\install-peruser.ps1" -SourcePath "$source\app" -Autostart

Your history is kept; the database upgrades itself on first start.

Uninstall

Installed the Windows service? Remove it first: in Cybernetic Bandwidth Monitor, open Settings › Running in the background and select Remove service. The uninstall script stops without changing anything while the service is installed.

Method A: from Windows Settings

  1. Open Settings › Apps › Installed apps (Windows 10: Settings › Apps › Apps & features).
  2. Find Cybernetic Bandwidth Monitor, select … › Uninstall, and confirm.

This stops Cybernetic Bandwidth Monitor, removes the program, the shortcut, the sign-in entry and the collected history. To keep the history, use method B with -KeepData.

Method B: from PowerShell

Remove Cybernetic Bandwidth Monitor and its collected history:

pwsh -NoProfile -ExecutionPolicy Bypass `
    -File "$env:LOCALAPPDATA\Programs\CyberneticBandwidth\uninstall-peruser.ps1"

Remove Cybernetic Bandwidth Monitor but keep the history in %LocalAppData%\CyberneticBandwidth for a later reinstall:

pwsh -NoProfile -ExecutionPolicy Bypass `
    -File "$env:LOCALAPPDATA\Programs\CyberneticBandwidth\uninstall-peruser.ps1" -KeepData
No PowerShell 7 any more? The uninstall script also runs in the built-in Windows PowerShell: replace pwsh with powershell in the commands above. Keep the ` at the end of the first line: it continues the command on the next line.

Check that it is gone

Test-Path "$env:LOCALAPPDATA\Programs\CyberneticBandwidth"     # False when removed
Test-Path "$env:LOCALAPPDATA\CyberneticBandwidth"              # False unless you used -KeepData
Get-Process CyberneticBandwidth -ErrorAction SilentlyContinue # prints nothing

Troubleshooting

What you seeWhat to do
"The term 'pwsh' is not recognized"PowerShell 7 is not installed, or the window was opened before it was. Install it (see the next page), then open a new PowerShell window.
Red parse error mentioning ?? in install-peruser.ps1The script was run with Windows PowerShell (powershell). Use pwsh as shown in step 4.
"running scripts is disabled on this system" or "is not digitally signed"Run step 3 (Unblock-File) and keep -ExecutionPolicy Bypass in the command. If a company policy still blocks it, ask IT, or use Option 1, which runs no scripts.
"Nothing to install at …"-SourcePath does not point at the app folder. Check $source and that $source\app\CyberneticBandwidth.exe exists.
Install fails to copy CyberneticBandwidth.exeCybernetic Bandwidth Monitor is still running. Exit it from the tray, then install again.
"Windows protected your PC"Run step 3 again, or click More info › Run anyway. Cybernetic Bandwidth Monitor is not code-signed, so SmartScreen does not recognise it.
Antivirus or company security tool blocks Cybernetic Bandwidth MonitorCybernetic Bandwidth Monitor reads per-application network usage and the connection list, which security tools can flag. On a work device, ask IT to allow it.
Anything elseLogs are in %LocalAppData%\CyberneticBandwidth\logs. Cybernetic Bandwidth Monitor's Settings and About pages both open the folder.
